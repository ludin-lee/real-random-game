# 02. 아트 디렉션 & UX

## 콘셉트: "황혼의 정원 (Twilight Garden)"
깊은 남보라 밤하늘 + 반딧불 + 사탕처럼 반짝이는 블록. 줄이 지워질 때 블록이 **꽃잎으로 흩날림**.
경쟁작(네온/보석 톤) 사이에서 썸네일 한 장으로 구분되는 따뜻한 톤이 목표.

## 에셋 전략: 에셋 0개
- 블록·꽃·파티클: Canvas 2D로 절차 생성, 색상×크기별 **스프라이트 캐시**(`src/render/sprites.ts`)로 프레임당 drawImage 1회.
- 사운드·BGM: WebAudio 합성(`src/services/audio.ts`), 전부 **펜타토닉 스케일** → 어떤 소리가 겹쳐도 불협화음이 없음.
- 결과: JS+CSS gzip ≈ 27KB. 다운로드 즉시 실행, 저사양 기기 대응.

## 조작감 (Game Feel) 체크리스트
- 집으면 블록이 실제 크기로 커지고 **손가락 위 1.3칸**으로 들려서 손가락에 가리지 않음 (마우스는 0.3칸).
- 스냅 허용: 정확한 칸이 안 맞으면 상하좌우 1칸까지 보정.
- 놓을 위치 고스트 + **지워질 줄을 미리 들고 있는 블록 색으로 칠해 보여줌**(블록블라스트 핵심 쾌감).
- 놓을 수 없는 트레이 블록은 반투명 처리 → 게임오버 예측 가능.
- 클리어: 보드 중심에서 바깥으로 퍼지는 웨이브, 흰 플래시, 꽃잎 파티클, 3줄 이상은 화면 흔들림.
- 칭찬 문구 단계: 좋아요! → 멋져요! → 대단해요! → 환상적! → 블룸타스틱!
- 햅틱: 집기/칸 이동 light, 배치 light, 1줄 medium, 2줄+ heavy, 게임오버 error 패턴.
- 꽃봉오리 수집 시 해당 꽃이 HUD 목표 칩으로 날아감.

## 접근성
- 색 외에 꽃 모양(튤립/블루벨/데이지)으로 목표 구분.
- 최소 터치 영역 44px, 사운드/음악/진동 개별 토글, 한국어/영어.

## 스토어 그래픽 가이드
- 아이콘: `public/icon.svg` (남보라 배경 + 블록 L자 + 분홍 꽃). 1024px PNG로 내보내 사용.
- 스크린샷 5장 순서: ① 다중 줄 클리어 순간("블룸타스틱!") ② 정원 모험 보드 ③ 오늘의 챌린지 메달 ④ 홈 화면 ⑤ 레벨 클리어 별 3개.
- `npm run e2e` 가 매번 `e2e/.results/*.png` 로 실제 화면을 뽑아주므로 스크린샷 소스로 재사용.
