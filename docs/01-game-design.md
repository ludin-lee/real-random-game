# 01. 기획서 (GDD) — 블룸 블록 / Bloom Blocks

## 한 줄 요약
**"블록 블라스트의 손맛 + 꽃이 피는 힐링 연출 + 매일 돌아올 이유."**
8×8 보드에 3개씩 주어지는 블록을 끌어다 놓고, 가로/세로 줄을 채우면 꽃잎이 터지며 사라지는 캐주얼 퍼즐.

## 왜 이 게임인가 (시장 근거)
| 근거 | 내용 |
|---|---|
| 장르 검증 | 2024–2026 하이브리드 캐주얼 1위권은 *Block Blast!*, *Block Puzzle* 류. 다운로드·리텐션 모두 최상위이며 광고 매출(IAA) 효율이 가장 높은 장르 중 하나 |
| 타깃 폭 | 25–55세, 성별 무관. 규칙 설명이 필요 없는 수준(1초 이해) → UA 단가(CPI)가 낮음 |
| 세션 구조 | 1판 3–8분, 판 종료마다 자연스러운 광고 지점 → 리워드/전면 광고 배치가 쉬움 |
| 개발 리스크 | 아트 에셋 0개(전부 코드 생성), 서버 불필요 → 작은 팀으로 출시·운영 가능 |
| 차별점 | ① 꽃 정원 테마의 힐링 연출(경쟁작은 대부분 네온/보석) ② **정원 모험** 레벨 모드(목표형) ③ **오늘의 챌린지** (전 세계 같은 블록 순서 → 공정 경쟁·공유 욕구) |

## 핵심 루프
```
블록 3개 받기 → 드래그 배치 → 줄 완성(꽃 터짐·점수·콤보) → 3개 다 쓰면 새 블록
     ↑                                                         │
     └──────────── 놓을 곳 없음 → 부활(광고/코인) or 결과 ←──────┘
```
- **긴장감의 원천**: 블록은 회전 불가, 공간은 점점 좁아짐.
- **해소의 원천**: 여러 줄 동시 클리어, 콤보, 올 클리어.

## 규칙
| 항목 | 값 | 비고 |
|---|---|---|
| 보드 | 8×8 | `src/core/board.ts` |
| 트레이 | 3개, 모두 쓰면 리필 | |
| 블록 종류 | 39종 (small 11 / medium 19 / large 9) | `src/core/shapes.ts` |
| 배치 점수 | 칸 수 × 1 | |
| 줄 점수 | 20 × L(L+1)/2 × 콤보 | 1줄 20, 2줄 60, 3줄 120, 4줄 200 |
| 콤보 | 클리어할 때마다 +1, **3번 연속** 클리어 못 하면 리셋 | 블록블라스트식 "한 트레이 안에 한 번만 깨면 유지" |
| 올 클리어 | +500 | |
| 게임오버 | 남은 블록 중 어느 것도 놓을 수 없을 때 | |
| 부활 | 1회 (광고 또는 250코인) — 가장 붐비는 4×4 영역 제거 + 새 트레이 | |

### 공정한 블록 생성기 ("억울하지 않은 랜덤")
`src/core/generator.ts`
1. 난이도(0→1)에 따라 small/medium/large 가중치를 보간. 클래식은 점수 6,000에서 최대 난이도.
2. **절대 즉사 금지**: 3개 중 최소 1개는 반드시 놓을 수 있음.
3. **도움 블록**: 30% 확률(보드가 55% 이상 찼으면 75%)로 1개는 "줄을 완성시킬 수 있는" 모양으로 교체.
4. 모든 생성은 시드 RNG → 리플레이·버그 재현·데일리 공정성 보장.

## 모드
### 🌸 클래식 (무한)
최고점 경쟁. 장기 리텐션의 축.

### 🌿 정원 모험 (레벨)
- 보드에 **이끼 돌** + **꽃봉오리**가 미리 배치되어 있고, 목표 꽃봉오리를 모두 피우면(=그 칸이 포함된 줄을 지우면) 클리어.
- 새로 받는 블록에도 꽃봉오리가 붙어 나옴(진행 불능 방지).
- 레벨은 **절차적·무한·결정적**(같은 레벨 번호 = 모든 기기에서 같은 배치). 좌우 대칭 배치로 "디자인된" 느낌.
- 별점: par 이하 이동 ⭐⭐⭐, 1.4배 이하 ⭐⭐, 그 외 ⭐.
- 난이도 곡선(봇 기준 승률): 1–10 ≈93%, 11–25 ≈82%, 26–50 ≈59%, 51–100 ≈30% (아이템·부활 없이). 실제 유저는 아이템/부활로 보정.

### 🌻 오늘의 챌린지
- 날짜 시드 → 전 세계 동일한 블록 순서.
- 메달: 🥉1,500 / 🥈4,000 / 🥇8,000 (봇 달성률 86% / 57% / 21%).
- 브론즈 이상 달성 시 **연속 출석(streak)** 증가 → 매일 들어올 이유.
